# Algoritmos 1

Exercícios desenvolvidos em linguagem C para a disciplina de Algoritmos I do curso de graduação em Engenharia de Software da Universidade Tecnológica Federal do Paraná (UTFPR).

### [Lista 0](./exercicios_0)

Tem como objetivo fixar os conceitos fundamentais de entrada e saída de dados em linguagem C, com foco nas funções printf() e scanf() da biblioteca <stdio.h>.

Os exercícios envolvem:

- Declaração e uso de variáveis (tipos int, float, double)
- Especificadores de formato (%d, %f, %lf)
- Leitura de dados com scanf (um valor)
- Cálculos simples com dados lidos do usuário
- Formatação de saída com printf (quebra de linha)

### [Lista 1](./exercicios_1)

Tem como objetivo aprofundar os conceitos de entrada e saída de dados em linguagem C estabelecidos na lista anterior, com foco nas funções printf() e scanf() da biblioteca <stdio.h>.

Os exercícios envolvem:

- Declaração e uso de variáveis 
- Especificadores de formato 
- Leitura de dados com scanf (um ou múltiplos valores)
- Cálculos simples com dados lidos do usuário
- Formatação de saída com printf (casas decimais, quebra de linha)

### [Lista 2](./exercicios_2)

Tem como objetivo fixar os conceitos fundamentais de operadores relacionais e lógicos e das estruturas de decisão if, else e switch em linguagem C, dando continuidade aos conhecimentos de entrada e saída de dados trabalhados anteriormente.

Os exercícios envolvem:

- Operadores relacionais (==, !=, <, >, <=, >=)
- Operadores lógicos (&&, ||, !)
- Estrutura básica do if (condição simples)
- Uso do else (condição alternativa)
- Encadeamento com else if (múltiplas condições)
- Estrutura de seleção múltipla com switch

### [Lista 3](./exercicios_3) e [Lista 4](./exercicios_4)

Tem como objetivo introduzir o uso da variável char e aprofundar os conceitos de operadores relacionais e lógicos e das estruturas de decisão if, else e switch em linguagem C estabelecidos na lista anterior.

Os exercícios envolvem:

- Declaração e uso de variáveis (tipos int, float, double, char)
- Especificadores de formato (%d, %f, %lf, %c)
- Operadores relacionais e lógicos
- Conversão de caracteres para caixa alta usando a função toupper() da biblioteca <ctype.h>
- Estruturas de decisão if, else e switch

### [Lista 5](./exercicios_5)

Tem como objetivo aprofundar ainda mais os conceitos das estruturas de decisão if, else e switch exercitados nas listas anteriores, explorando o conceito de níveis de entradas e aninhamento de estruturas condicionais em linguagem C.

Os exercícios envolvem:

- Operadores relacionais e lógicos
- Estruturas de decisão if, else e switch
- Modelagem de fluxos de decisão a partir de diferentes níveis de entradas
- Desenvolvimento de soluções com estruturas condicionais aninhadas
